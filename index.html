统一上报接口

后续服务只需按同一份 JSON 协议推送状态。

POST https://liangzai666.com/status-api/v1/status　 Authorization: Bearer <STATUS_HUB_TOKEN>
{
  "service_id": "my-service",
  "name": "我的服务",
  "state": "healthy",
  "message": "运行正常",
  "observed_at": "2026-09-09T08:00:00Z",
  "ttl_seconds": 120,
  "metrics": {"queue": 0},
  "details": {"version": "1.0.0"}
}
状态枚举
healthy      正常
degraded     部分异常
down         停止或不可用
maintenance  维护中
unknown      超过 TTL 未上报
